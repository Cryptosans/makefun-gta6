Solara Bay — an original open-world crime game: a sun-soaked 5x5-block city to explore on foot and by car, traffic and pedestrians, cars to steal, a wanted level with police who respond, 6 story missions, combat and a live minimap. Built with three.js, runs fully offline in a desktop browser.

## Run it

```sh
python3 -m http.server 8000 --directory game
```

Then open http://localhost:8000 in desktop Chrome.
